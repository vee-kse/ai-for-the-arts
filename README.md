# ai-for-the-arts

This repository holds my work for AI for the Arts and Humanities (A) at the University of Glasgow. I'll use it to collect the weekly lab notebooks and the final design project in one place.

I came into the course with two years of computer science behind me, covering Java, Python and object-oriented programming. The course focuses on reading code and explaining it to people who don't write it, so that is where I am aiming.

## Goals

- Read Python code used in machine learning and explain each step in plain English to a non-technical audience.
- Work through the machine learning pipeline notebook, and record where my thinking matched my peer group and where it split.
- Use Microsoft Copilot as a coding assistant, and document where it helped and where it fell short.
- Design a creative application of a large language model, with a written critique of its social and cultural effects.

## Contents

- `coding_exercises.ipynb`: Python basics, Copilot prompts, media as data, sklearn and pandas
- `Machine-Learning-by-Example-from-Start-to-End.ipynb`: the machine learning workflow, with my answers and reflections
